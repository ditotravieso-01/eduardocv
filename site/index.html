Proyectos destacados

Casos reales.

TraviesoWorks Cloud

Infraestructura self-hosted completa sobre un VPS: VPN, DNS cifrado, ERP, documentación, archivos y oficina. Todo orquestado con Docker y expuesto con SSL.

  • Headscale + WireGuard + AdGuard como servicio de VPN con bloqueo de anuncios.
  • Odoo 19 + Nextcloud + OnlyOffice + Docmost en contenedores aislados.
  • Nginx Proxy Manager con SSL automático (Let's Encrypt) para 8 subdominios.
  • Políticas de red segmentadas y DNS Split para clientes.

Resultado: 8 servicios en producción corriendo sobre un único VPS, con SSL automático y sin intervención manual para renovaciones.

Tecnologías: Docker · Portainer · WireGuard · Headscale · AdGuard · NPM · Odoo

TraviesoPrint

ERP web propio construido desde cero para un taller de impresión gráfica. Reemplaza progresivamente a Odoo como frontend de producción. Backend en Flask con SQLAlchemy, ~28 tablas y 12 módulos organizados por dominio. Inspirado en conceptos de Odoo (modelos, kanban, workflow) pero implementado a medida.

  • 12 módulos independientes por dominio: inventario, órdenes, etiquetas, carteles, workflow, empleados, nómina, calendario, notificaciones, admin.
  • Cálculo de merma operativa por paño, reservas de stock y dashboard con KPIs personalizables.
  • Autenticación LDAP contra Active Directory sobre LDAPS (TLS 1.2+), con PKI interna emitida con XCA.
  • Despliegue en producción con systemd + nginx + gunicorn sobre Ubuntu 24.04 LTS, migraciones con Alembic.

Resultado: el taller dejó de depender de hojas de cálculo para inventario y producción. La merma por paño y la nómina de empleados ahora se calculan solas. Todo el equipo trabaja sobre el mismo sistema.

Tecnologías: Python · Flask · SQLAlchemy · Jinja2 · SQLite · PostgreSQL · LDAP · Nginx · Gunicorn · Chart.js

Infraestructura Cairostudio

Rediseño completo de la infraestructura tecnológica de un taller de impresión gráfica. Diseño de red virtual segmentada, servidor de virtualización, almacenamiento centralizado y dominio propio.

  • Servidor Proxmox con segmentación de red virtual: DMZ, LAN y WAN aisladas.
  • TrueNAS como almacenamiento centralizado, reemplazando el FTP antiguo.
  • Active Directory en Windows Server + PKI interna (XCA) + LDAPS end-to-end verificado.
  • Kerio Control como firewall perimetral y Headscale/WireGuard como servicio de acceso remoto mensual.
  • Aseguramiento de conectividad para los flujos de producción e impresión del taller.

Resultado: almacenamiento centralizado (NAS), dominio propio, correo internacional y acceso remoto permanente. Red segmentada en DMZ/LAN/WAN, con servicios críticos funcionando sin depender de internet.

Tecnologías: Proxmox · TrueNAS · Windows Server · Active Directory · PKI · Kerio · Headscale · WireGuard · XCA · Certificados SSL
